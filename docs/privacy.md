# 公开边界

公开包采用新建文件的方式整理；不复制私人库的记忆正文、Git 历史、机器映射、审计流水、原始归档、账号状态和定时任务配置。`examples/` 的人名、项目和事件均为虚构。

默认忽略 `memory/` 正文、本机路径文件、`audit/`、`archive/`、`environment/`、编辑器配置与常见凭据文件。空目录标记可保留。

`index/projects.json` 为方便模板分发保留在版本管理中；私人库中的真实注册表可能包含项目名称和知识入口，也需要保护。推荐始终将私人工作区与公开模板仓库分开。

`.gitignore` 不能移除已跟踪文件，也不能清理提交历史。再次分享时从允许公开的模板文件重新构建发布目录，并逐项审阅文件名、内容和历史。自动扫描仅是辅助，不能保证识别所有私密信息。

不将原库附带的第三方技能打包发布；确需分发时先核对其许可与归属。

# 每日日记

汇总运行当天所有有依据的重要活动，包含项目和非项目事项、实际产物、重要讨论、决策与纠正。不推断未提供的私人生活、情绪或经历。

1. 明确日期与使用者时区；读取当天相关知识页、交付物及获准来源。
2. 聊天中声称完成不等于产物或业务状态已完成；重要结论回读产物或权威来源。
3. 保留来源时间、核验状态和覆盖缺口。来源返回空不等于当天没有活动；来源清单不是活动范围白名单。
4. 按主题去重更新 `memory/日记/YYYY/MM/YYYY-MM-DD.md`，保留原有有效记录。项目知识另按路由规则回写。
5. 失败不推进来源的成功水位。水位只适用于实际查询范围，不能排除新增来源和未覆盖主题。
6. 刷新导航、回读日记及导航，追加必要审计。无新事实不编造进展。

本文不安装或启用调度器。需要定时运行时，另行明确时区、来源、权限、运行与通知平台；每次开启新聊天，按复杂程度和重要性选择模型与推理强度。配置创建、实际触发、执行完成和通知送达分别验证。无实质变化时静默，仅变化、完成、失败或需用户处理时通知。

截图只能支持可见内容；应用切换不证明沟通完成，输入片段不证明消息已发送。采集来源和范围由使用者授权，不默认开启后台监控。

配置与验收见 [每日日记定时任务配置](../docs/daily-diary-scheduling.md)，可复制提示词和参数模板；这些文件本身不启用调度。

# Agent Memory Kit

一套基于本地 Markdown 的 Agent 长期记忆工作流。公开的是目录、规则和工具；使用者的记忆保存在自己的本地知识库中。

适合希望让 AI 在跨会话工作中读取既有背景、找到正确项目、保留决策依据，并在任务结束后更新知识的人。可用普通编辑器阅读；内置 Obsidian Vault 配置和模板，也可使用普通 Markdown 编辑器。

## 它解决什么

- **先读取背景**：涉及既有经历、方案和延续工作时，先定位并实际读取资料。
- **准确路由**：项目身份、机器目录和权威知识目标分开管理。
- **有依据地更新**：记录来源日期与核验状态，保留未知；重要变更写后回读。
- **日级汇总**：将项目与非项目活动按证据整理成日记，注明覆盖缺口。
- **内容和运行配置分离**：`memory/` 是阅读区，索引、工作流、审计位于外层。

这是文件与 Agent 指令组成的工作流。检索、判断和回写由接入的 Agent 执行；没有自带模型、向量数据库、后台采集服务或强制执行引擎。遵循规则的程度取决于 Agent 和宿主工具。平台自带记忆另行管理。

## 快速开始

需要 Python 3.10 或更高版本，无第三方依赖。在仓库根目录执行：

```sh
python3 tools/init.py --destination ../my-agent-knowledge
cd ../my-agent-knowledge
python3 tools/validate.py
python3 tools/refresh.py
```

初始化目标必须不存在，防止覆盖已有知识。它创建一个与公共仓库分开的私人工作目录，不包含 Git 历史。

1. 将 `AGENTS.md` 的相关规则接入你使用的 Agent 指令入口，并明确告知该私人知识库的绝对路径。不同宿主是否自动加载指令应单独核验。
2. 根据 `examples/` 的虚构示例，在私人库中登记自己的项目与路径。
3. 让 Agent 按“检索 → 读取 → 核验 → 执行 → 回写 → 回读”的流程工作。
4. 如使用 Obsidian，只打开私人库的 `memory/`；初始化已配置日记路径和笔记模板。详见 [Obsidian 使用指南](docs/obsidian.md)。

首次可尝试：

> 请读取这套知识库的入口和工作流，查看项目索引。根据我提供的材料登记一个项目，标明来源与待验证事项；写后验证并刷新导航。

模板不预设外部系统访问或写入授权。按你的实际权限修改 Agent 规则；公开示例不包含账号或已配置的定时任务。

## 目录

```text
Agent 知识库.md          阅读入口
AGENTS.md                Agent 接入规则
memory/                  私人记忆与生成导航（内容默认忽略）
index/projects.json      空项目注册表
index/local-paths.example.json  机器路径示例
workflows/               检索、路由、回写和日记规则
templates/               项目、日记、经验与审计模板
examples/                完全虚构的示例，默认不导入
tools/                  初始化、验证、导航生成工具
```

详见 [设计说明](docs/design.md)、[接入与使用](docs/usage.md)、[公开边界](docs/privacy.md) 和 [发布说明](docs/releasing.md)。

## 验证范围

工具检查索引结构、唯一 ID、知识目标存在性与本机路径映射，并生成导航。它们不验证记忆事实真假，不替代人工审阅，也不保证自动阻止泄密或并发写入。

# 创建任务的请求模板

这是给具备调度能力的助手/平台使用的请求文本，复制本文件不会创建任务。先填好占位符并确认授权范围；请勿把真实路径或来源账号回传到公共仓库。

```text
请创建一个独立的每日日记定时任务，每次运行开启一个新聊天，不在现有聊天中循环唤醒。

时区：<TIMEZONE>
执行时间：每天 <LOCAL_TIME>（该时区当地时间）
知识库根目录：<KNOWLEDGE_ROOT>
允许读取的本地材料目录：<AUTHORIZED_LOCAL_ROOTS>（无则填无）
允许读取的已连接来源：<AUTHORIZED_CONNECTED_SOURCES>（无则填无）

将知识库 templates/automations/daily-diary.prompt.md 的占位符替换后，保存其完整正文作为每次执行提示词；不要只保存一个未来可能无法访问的文件链接。

执行环境必须能实际访问私人知识库。仅授权在既定知识库内写入当日日记、导航、最小审计；已有项目知识只有在我已授权维护且目标核实后才能更新。不得公开私人内容。

启动每次执行聊天前，按当次材料量、复杂程度与重要性选择可用模型及推理强度，不写死模型名；记录选择依据。若平台不能按次选择，先明确报告这一缺口并提出可行适配，不把提示词当成已实现的模型切换器。

目标日期固定为每次运行开始时的本地日期，截止时间为启动时刻；只处理当日，不自动补跑历史。重叠执行时采用单写者，已有任务要先检查重复，避免双重触发。

只在实质变化、完成且有内容变化、失败或需要我处理时，在既定任务渠道通知一次；无变化静默。不得新增第三方外发通知。

先验证路径、权限和来源，手工试运行并回读结果后，再启用调度。完成后分别报告配置是否保存、下一次触发时间是否核实、实际运行是否验证、通知是否验证；未验证项保留未知。
```
